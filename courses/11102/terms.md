# Terms used in `dot-product` (Arabic ↔ Hebrew)
- الضرب السلمي ↔ מכפלה סקלרית (dot product) ; نتيجته عدد ↔ סקלר
- متجه ↔ ווקטור ; المتجه الصفري ↔ ווקטור האפס ; غير صفري ↔ שונה מווקטור האפס
- زاوية (بين المتجهين) ↔ זווית ; حادة ↔ חדה ; قائمة ↔ ישרה ; منفرجة ↔ קהה
- طول ↔ אורך ; جيب التمام (cos) ↔ קוסינוס
- إحداثيات ↔ קואורדינטות
- متعامدان ↔ מאונכים / ניצבים / אורתוגונליים
- ادّعاء ↔ טענה ; تعريف ↔ הגדרה ; مثال ↔ דוגמה ; ملاحظة ↔ הערה
- تبديلية ↔ חילוף ; توزيعية ↔ פילוג
- الظل (صورة الدرس فقط، مش مصطلح الكتيّب) = إسقاط المتجه ↔ היטל
